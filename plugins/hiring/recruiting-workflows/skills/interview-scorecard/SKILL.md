# Interview scorecard

Structured interviews beat unstructured ones on predictive validity and on fairness. This skill produces a scorecard that every interviewer uses the same way.

## Building a scorecard for a role

1. Extract 4 to 6 **competencies** from the job description (e.g. "System design", "Ownership", "Communication"). Fewer, well-defined competencies beat a long checklist.
2. For each competency write:
   - One **behavioral question** ("Tell me about a time…") and one **follow-up probe**.
   - A **4-point anchored scale**: 1 = clear miss, 2 = partial, 3 = meets bar, 4 = clearly exceeds. Write one sentence describing what a 2 and a 4 look like so interviewers calibrate the same way.
3. Assign each competency to a specific interview in the loop so no competency is assessed by everyone and none by no one.
4. Output as a markdown table plus a short "how to score" note.

## Filling in a scorecard after an interview

- Ask for the interviewer's raw notes, then map evidence to competencies. Quote the evidence; do not paraphrase into conclusions.
- Score only competencies that were actually probed. Mark the rest "not assessed" rather than guessing.
- End with a one-line hire / no-hire recommendation and the single strongest reason for it.

## Guardrails

- Never infer or record protected characteristics (age, family status, ethnicity, religion, disability, etc.).
- Flag questions that could be construed as discriminatory before they are asked.
