# Brand voice

Consistency is what makes a voice recognisable. This skill keeps every piece of copy sounding like it came from the same company.

## Find the voice guide first

1. Look for a voice or style guide in the project: files named like `brand-voice.md`, `style-guide.md`, `tone.md`, or a `marketing/` folder.
2. If one exists, follow it exactly and cite it when you make a judgement call.
3. If none exists, ask the user for three adjectives that describe the brand and one that it must never be, then propose a short guide in the format below and offer to save it.

## Voice guide format

```
We are:      [adjective] / [adjective] / [adjective]
We are not:  [adjective]
We say:      "[example phrase]"
We never say: "[example phrase]"
Reading level: [e.g. plain English, grade 8]
```

## Reviewing copy

Return a table with columns: original line, issue, rewrite. Only include lines that need a change. Common issues: passive voice, jargon the audience would not use, more than one idea per sentence, claims with no proof, exclamation marks, "we" where "you" would land harder.

## Writing copy

- Lead with the reader's problem, not the product.
- One call to action per piece.
- Headline under 10 words, body sentences under 20.
- Never fabricate testimonials, statistics or awards; mark them `[needs source]`.
